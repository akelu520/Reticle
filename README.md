# Reticle

一个小小好用的截图工具。macOS 原生实现，支持截图、标注、贴图、提取文字、滚动截图、录屏和截图历史，安装包约 1 MB，常驻内存约 11 MB。

## 功能进度

| 里程碑 | 内容 | 状态 |
|---|---|---|
| M1 核心截图 | 菜单栏常驻、⇧⌘A 截图、窗口识别、放大镜、选区调整、复制/下载 | ✅ |
| M2 标注编辑 | 矩形、椭圆、箭头、画笔、高亮、马赛克、文本、标签、撤销、水印 | ✅ |
| M3 贴图 + 提取文字 + 翻译 | 固定到屏幕、OCR、翻译（macOS 15+） | ✅ |
| M4 滚动截图 | 手动/自动滚动拼接长图 | ✅ |
| M5 录屏 | MP4 / GIF、剪辑 | ✅ |
| M6 截图历史 | 菜单栏 › 最近截图（最近 20 张） | ✅ |

设计文档：[docs/superpowers/specs/2026-09-25-reticle-design.md](docs/superpowers/specs/2026-09-25-reticle-design.md)

## 使用

- ⇧⌘A 开始截图（可在设置中修改）
- 悬停自动识别窗口，单击选中窗口，拖拽框选任意区域
- 拖动手柄调整大小，拖动选区移动，方向键逐点微调
- 工具栏选择 矩形 / 椭圆 / 箭头 / 画笔 / 高亮 / 马赛克 / 文本 / 标签，二级工具栏调粗细、字号和颜色；按住 ⇧ 画正方形、正圆或 45° 箭头
- 标签：点击放置，点击定位点翻转方向；双击文本或标签重新编辑
- 不选工具时点击标注可选中、拖动、Delete 删除、调整颜色/粗细
- ⌘Z 撤销，⇧⌘Z 重做；水印可设置文字、透明度和颜色
- 滚动截图：屏幕顶部选“滚动截图”后框选并点“开始滚动截图”，或在工具栏点滚动截图；缓慢上下滚动，或点“自动滚动”（需要辅助功能权限）；完成后可编辑、保存、取消、保存到剪切板
- 📌 固定到屏幕：截图浮在最上层，拖动移动，双击或 Esc 关闭，右键复制/保存
- 提取文字：屏幕顶部选“提取文字”后框选，或在工具栏点提取文字；可编辑、复制全文、点击链接，macOS 15+ 可翻译
- 录屏：⌥⇧R（可在设置中修改）或菜单“录屏”，框选区域后选 MP4 / GIF 开始录制，最长 1 小时；结束后可剪辑时长，下载或复制到剪贴板
- 最近截图：菜单栏 › 最近截图，点击重新复制，按住 ⌥ 点击用预览打开；可在设置中关闭“保存截图历史”
- 回车 / 双击 / ✓ 保存到剪切板；↓ 下载；Esc / ✕ 取消

第一次截图时需要在“系统设置 › 隐私与安全性 › 屏幕与系统录音”中允许 Reticle。

## 架构

- `Reticle`：菜单栏 App，负责快捷键、截图、标注、贴图、滚动截图、翻译、设置
- `ReticleWorker`：内置在 App 包里的后台进程，按需启动，负责提取文字（Vision）和录屏（AVFoundation），完成即退出，这些框架的内存不会留在菜单栏 App 里
- `Packages/ReticleCore`：几何、标注、渲染、拼接、OCR 等纯逻辑，单元测试覆盖

## 开发

需要 Xcode 16+ 和 [XcodeGen](https://github.com/yonaskolb/XcodeGen)（`brew install xcodegen`）。

```bash
swift test --package-path Packages/ReticleCore   # 单元测试
xcodegen generate && open Reticle.xcodeproj       # 生成并打开工程
scripts/build-dmg.sh                              # 打包 build/Reticle-<版本>.dmg
```

端到端测试（DEBUG 构建内置，Release 不包含）：

```bash
scripts/e2e.sh   # 编译 App 与滚动辅助窗口，驱动真实窗口跑 116 项检查，退出码 = 失败数
```

- 前 9 组用静态演示图代替截屏，不需要权限；通过合成鼠标/键盘事件驱动真实界面，覆盖选区、全部标注工具、撤销、水印、复制/下载/取消、贴图、提取文字、滚动截图界面、长图编辑、录屏预览与 MP4/GIF 导出、设置与快捷键
- 最后一组在有“屏幕录制”权限时使用真实屏幕：真实截屏与窗口吸附、真实滚动截图（辅助程序自动滚动一张长页面，结束后逐行校验无断层）、真实录屏 3 秒并检查时长与分辨率
- 运行期间屏幕上会短暂出现截图界面；剪贴板内容会在结束时恢复

调试时可以不申请权限，用一张静态图代替截屏：

```bash
RETICLE_DEMO_IMAGE=/path/to/image.png RETICLE_AUTOSTART=1 \
  build/dd/Build/Products/Debug/Reticle.app/Contents/MacOS/Reticle
```

> ad-hoc 签名每次构建都会变，系统会把重新构建的 App 当成新 App，需要重新授予屏幕录制权限。
