## 新变化
- **截图界面全面改版**：工具栏按功能分组（绘图工具 ｜ 马赛克 高亮 水印 固定 翻译 提取文字 识别二维码 滚动截图 ｜ 撤销 下载 取消 完成），可拖动；悬停显示提示；顶部新增模式栏（截图 / 滚动截图 / 录屏 / 提取文字）
- **新增直线工具**；标签改为带指示角的气泡样式
- **二级工具栏**：紧贴所属工具并带指示箭头，按工具提供不同选项
  - 文本：普通 / 底色 / 描边三种样式，字号 12–48pt
  - 马赛克：马赛克或模糊，画笔或框选，强度可调
  - 高亮：聚光灯效果（压暗选区外），矩形 / 椭圆 / 圆角矩形，不透明度可调
  - 水印：最多 16 个字符，可调不透明度和颜色
- **识别二维码**：框选二维码即可识别，结果中的链接可直接打开
- **按内容启用按钮**：选区内有文字才可提取文字，有二维码才可识别二维码
- **放大镜**：显示坐标和颜色值，⌘C 复制色值，Shift 切换 RGB / HEX
- 桌面小组件也可以被吸附选中

## 修复
- 已授予屏幕录制权限却仍反复提示：签名改为固定的应用标识，以后更新不再丢失授权
- 截图失败时的错误弹窗可能被遮罩挡住导致卡住，改为不阻塞的提示并说明原因
- 遮罩窗口未激活时，二级工具栏的颜色和粗细首次点击无效
- 识别结果在截图结束后才返回时可能闪退

## 安装
1. 下载 `Reticle-0.4.0.dmg`，把 Reticle 拖进“应用程序”（可直接覆盖旧版本）
2. 本版本为 ad-hoc 签名（未经 Apple 公证），首次打开会提示“Apple 无法验证”。点“完成”，然后任选其一：
   - 打开“系统设置 › 隐私与安全性”，在页面底部点“仍要打开”
   - 或在终端执行：`xattr -dr com.apple.quarantine /Applications/Reticle.app`
3. 从 0.3.0 及更早版本升级时，需要最后一次在“系统设置 › 隐私与安全性 › 屏幕与系统录音”中重新允许 Reticle（如列表中已有 Reticle 但不生效，先移除再添加），然后重新打开。之后的版本更新会保留授权

要求 macOS 14 Sonoma 或更高版本。
