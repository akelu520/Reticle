- **全新图标**：App 图标换成 Reticle 自己的取景框标志，Dock、应用程序文件夹和访达中均可见
- **菜单栏图标**：换成同一标志的单色版，随浅色 / 深色菜单栏自动变色

## 改进
- 多显示器下经过完整测试：每块显示器独立截取、按各自分辨率输出，跨屏框选时另一块屏幕的选区会自动清除

## 安装
1. 下载 `Reticle-0.3.0.dmg`，把 Reticle 拖进“应用程序”（可直接覆盖旧版本）
2. 本版本为 ad-hoc 签名（未经 Apple 公证），首次打开会提示“Apple 无法验证”。点“完成”，然后任选其一：
   - 打开“系统设置 › 隐私与安全性”，在页面底部点“仍要打开”
   - 或在终端执行：`xattr -dr com.apple.quarantine /Applications/Reticle.app`
3. 覆盖安装后需在“系统设置 › 隐私与安全性 › 屏幕与系统录音”中重新允许 Reticle（如列表中已有 Reticle 但不生效，先移除再添加），然后重新打开

要求 macOS 14 Sonoma 或更高版本。
