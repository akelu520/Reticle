# Reticle 设计文档

- 日期：2026-09-25
- 状态：待评审
- 目标：做一个 macOS 原生截图工具，覆盖截图、标注、贴图、提取文字、滚动截图、录屏，安装包和内存占用尽可能小。

## 1. 背景与目标

好用的截图功能常常附带在体积庞大的客户端里，为了截图常驻一个几百 MB 的程序不划算。Reticle 只做截图这一件事。

### 1.1 功能范围

截图（窗口识别、放大镜、选区编辑）、标注（形状、画笔、高亮、马赛克、文本、标签、水印、撤销）、固定到屏幕、提取文字与翻译、滚动截图、录屏（MP4 / GIF），以及截图历史。细节交互按常见截图工具的习惯设计。

### 1.2 明确不做

- 和即时通讯绑定的能力（发送到会话、从聊天输入框唤起）。独立 App 不需要，由"复制到剪贴板"替代。
- 使用任何第三方的图标和品牌素材。视觉资源全部自行设计。
- Windows 和 Linux。

### 1.3 非功能目标（验收指标）

| 指标 | 目标 |
|---|---|
| 最低系统 | macOS 14 Sonoma |
| .app 体积 | ≤ 10 MB；DMG ≤ 5 MB |
| 空闲内存（`footprint` 的 phys_footprint，即活动监视器里的“内存”） | ≤ 25 MB |
| 截图会话峰值内存 | 单块 5K 屏 ≤ 150 MB，会话结束后 5 秒内回落到空闲水平 |
| 按快捷键到遮罩出现 | ≤ 150 ms |
| 第三方依赖 | 0 个（只用系统框架） |

## 2. 技术选型

- 语言：Swift 5.10+ / Swift 6 语言模式
- UI：**AppKit + Core Animation**。截图遮罩、选区、标注画布、工具栏都用 `NSWindow`、`NSView` 和 `CALayer`；设置页、OCR/翻译面板用 SwiftUI（嵌在 `NSHostingView` 里）
- 截图：ScreenCaptureKit（`SCScreenshotManager` 截静态图，`SCStream` 用于滚动截图取帧和录屏）
- OCR：Vision `VNRecognizeTextRequest`
- 翻译：Translation 框架（macOS 15+）
- 录屏编码：AVFoundation `AVAssetWriter`（H.264 MP4）；GIF 用 ImageIO `CGImageDestination`
- 全局快捷键：Carbon `RegisterEventHotKey`（不需要辅助功能权限）
- 开机启动：`SMAppService.mainApp`
- 工程：XcodeGen（`project.yml` 生成 `.xcodeproj`，生成物不入库）+ 本地 Swift Package `ReticleCore`
- 分发：不开沙盒，GitHub Releases 发 DMG，ad-hoc 签名；CI 预留 Developer ID 签名和公证步骤

### 3.0 进程划分

- **Reticle**（菜单栏 App）：快捷键、截图、标注、贴图、滚动截图、翻译、设置。常驻进程，保持最小内存。
- **ReticleWorker**（`Contents/MacOS/ReticleWorker`，按需启动、任务结束即退出）：内存大户放在这里，退出后内存全部归还系统。
  - `ocr <png>`：Vision 文字识别，结果以 JSON 输出。
  - `record <json>`：接管录屏全流程（边框、计时、结束、预览剪辑、导出、复制/保存），预览窗口关闭后退出；再按 ⌥⇧R 由主 App 发 `SIGUSR1` 结束录制。
  - 由主 App 直接启动，沿用 Reticle 的屏幕录制权限。
  - 翻译仍在主 App：`TranslationSession` 只能通过 SwiftUI 的 `.translationTask` 获得。
- 共享代码在 `Shared/`（偏好、临时目录、显示器 ID、主 App 与 worker 的协议），纯逻辑在 ReticleCore。

### 3.1 设计原则

1. **ReticleCore 只依赖 Foundation、CoreGraphics、CoreImage、ImageIO**，所有逻辑都能不开界面单测。
2. **屏幕显示和导出用同一套渲染代码**：画布的 `draw(_:)` 调用 `Render` 模块把标注画到 `CGContext`，导出时对同一组标注用像素尺寸的 context 再画一遍，保证所见即所得。
3. **按需创建，用完即毁**：空闲时只保留菜单栏图标和快捷键监听；遮罩窗口、截图位图、SCStream 都在会话开始时创建、结束时释放。
4. **标注画布可以放在两种宿主里**：`AnnotationCanvasView` 既能嵌进全屏遮罩（普通截图），也能嵌进可滚动的普通窗口（滚动截图生成的长图超出屏幕时用）。

### 3.2 坐标系约定

- 截图底图以**像素**存储（`CGImage`，Retina 下尺寸 = 点 × scale）。
- 标注坐标用**底图像素坐标系**（原点在左上，y 轴向下），与显示缩放无关，导出时直接裁剪选区。
- AppKit 全局坐标（原点在主屏左下）和 ScreenCaptureKit/CG 坐标（原点在左上）的换算集中在 `Geometry.CoordinateSpace`，其他地方不自己换算。

## 4. 功能设计

### 4.1 应用外壳

- **菜单栏菜单**：截图（⌘⇧A）、录屏（⌥⇧R）、设置…、关于 Reticle、退出。
- **默认快捷键**：截图 **⌘⇧A**，录屏 **⌥⇧R**，都能在设置里改。
- 快捷键注册失败（被其他 App 占用）时，在菜单栏菜单项上显示警告，设置页提示改键。
- **权限**：
  - 屏幕录制：第一次截图时用 `CGPreflightScreenCaptureAccess` 检查；没有权限就弹引导窗口（说明原因 + "打开系统设置"按钮），不进入截图会话。
  - 辅助功能：只有**自动滚动**用到，第一次点"自动滚动"时再申请。
- **设置页**：截图快捷键、录屏快捷键、开机启动、默认保存目录。

### 4.2 截图会话（M1）

流程：

1. 按 ⌘⇧A → 对每块显示器调用 `SCScreenshotManager.captureImage` 取冻结画面（排除 Reticle 自己的窗口），同时用 `SCShareableContent` 和 `CGWindowListCopyWindowInfo` 拿到窗口列表（frame + 层级顺序），用于识别窗口。
2. 每块显示器盖一个无边框遮罩窗口（`level = .screenSaver`，覆盖菜单栏和 Dock），显示冻结画面，上面盖一层半透明暗色蒙版。
3. **顶部模式栏**：显示在鼠标所在屏幕的顶部中间，包含 `截图`（默认）、`滚动截图`、`提取文字`。选择模式后，框选完成时直接进入对应流程。
4. **选区之前**：
   - 鼠标悬停时自动识别光标下最上层的窗口，高亮它的边框；不在任何窗口上时高亮整块屏幕。
   - 单击 = 选中高亮区域；按下拖拽 = 自定义矩形。
   - 光标旁显示放大镜：取 15×15 像素放大 8 倍，带十字准星，下面显示坐标和选区尺寸。
5. **选区之后**：
   - 8 个手柄可调大小，拖动选区内部可以移动，方向键每次移动 1 点。
   - 选区左上角外侧显示尺寸标签（宽 × 高，单位是像素）。
   - 选区限制在单块显示器内；鼠标按下时所在的屏幕就是选区所在屏幕。
   - 选区下方出现**主工具栏**（空间不够时放到上方或选区内部）。
6. **主工具栏**（从左到右）：
   `矩形` `椭圆` `箭头` `画笔` `高亮` `马赛克` `文本` `标签` ｜ `撤销` ｜ `水印` `固定到屏幕` `提取文字` `滚动截图` ｜ `取消` `下载` `保存到剪切板`
   - M1 只有：`取消`、`下载`、`保存到剪切板`，其余按钮按里程碑陆续加上。
7. **结束**：
   - `保存到剪切板`、双击选区或回车：把合成图以 PNG 写入 `NSPasteboard`，结束会话。
   - `下载`：弹 `NSSavePanel`，默认目录是设置里的保存目录（初始为"下载"），文件名 `Reticle_yyyy-MM-dd_HH-mm-ss.png`；保存后结束会话。
   - `取消` 或 Esc：结束会话。正在输入文字时，第一次按 Esc 先结束文字输入。

### 4.3 标注编辑（M2）

所有工具都在**选区内**生效，画到选区外的部分导出时会被裁掉。点击工具后在主工具栏下方出现**二级工具栏**：

| 工具 | 操作 | 二级工具栏 |
|---|---|---|
| 矩形 / 椭圆 | 拖拽绘制；按住 Shift 画正方形或正圆 | 左：线条粗细（细/中/粗）；右：颜色 |
| 箭头 | 从起点拖到终点，箭头头部大小跟粗细成比例 | 同上 |
| 画笔 | 自由绘制，路径做平滑处理 | 同上 |
| 高亮 | 类似荧光笔的自由绘制：半透明（α 0.4）、宽笔触（普通混合；屏幕画布是透明图层，正片叠底无法和底图一致） | 同上（默认黄色） |
| 马赛克 | 两种模式：**画笔马赛克**（沿鼠标轨迹打码）和**框选马赛克**（拖一个矩形打码） | 左：模式切换 + 画笔粗细 |
| 文本 | 点击选区内任意位置，出现输入框（`NSTextView`），直接输入，支持换行；点击其他地方结束输入 | 文字大小（小/中/大 = 14/18/24pt）、颜色 |
| 标签 | 点击选区内任意位置，放一个**定位点**（彩色圆点），旁边连着一个文字气泡，直接输入内容；**点击定位点可以翻转标签方向**（气泡在左边或右边） | 字体大小、定位点颜色 |

- **颜色板**（7 色）：红 `#F54A45`、橙 `#FF8800`、黄 `#FFC60A`、绿 `#34C724`、蓝 `#3370FF`、黑 `#1F2329`、白 `#FFFFFF`。默认红色；每个工具记住自己上一次用的颜色和粗细。
- **粗细**：细 / 中 / 粗 = 2 / 4 / 8 像素（按底图像素缩放）。
- **撤销**：工具栏的 `撤销` 按钮和 ⌘Z 都能撤销上一步；⌘⇧Z 重做，只有快捷键，没有按钮。
- **选中已有标注**：没在绘制时，点击一个标注可以选中它（显示外框），然后能拖动位置、按 Delete 删除；在二级工具栏改颜色或粗细会作用到它。以上都进入撤销栈。
- **马赛克实现**：会话开始时用 `CIPixellate` 预先生成整张底图的马赛克版本（块大小 ≈ 12 像素 × scale），打码区域就是用笔触或矩形做蒙版，从马赛克版本里取像素。马赛克总是画在其他标注下面。
- **水印**：点 `水印` 按钮弹出面板，可以输入文字、调透明度（10%–100%）、选颜色。确认后在选区内平铺旋转 −30° 的文字。一张图只有一个水印，再点就是编辑；清空文字就是移除。水印的增删改也进撤销栈。
- **渲染顺序**：底图 → 马赛克 → 高亮 → 形状/画笔/箭头 → 文本/标签 → 水印。

数据模型（ReticleCore/Annotation）：

```swift
enum AnnotationKind { case rect, ellipse, arrow, pen, highlight, mosaicBrush, mosaicBox, text, label }
struct Annotation: Identifiable, Equatable {
    let id: UUID
    var kind: AnnotationKind
    var points: [CGPoint]        // 形状用 [起点, 终点]；笔触用采样点
    var style: Style             // color, lineWidth, fontSize
    var text: String?            // text / label
    var labelFlipped: Bool       // label 方向
}
struct Watermark: Equatable { var text: String; var opacity: CGFloat; var color: RGBA }
struct Document { var baseSize: CGSize; var crop: CGRect; var annotations: [Annotation]; var watermark: Watermark? }
```

撤销栈存 `Document` 快照（标注数据很小，存快照比写逆操作简单可靠），上限 100 步。

### 4.4 固定到屏幕（M3）

- 点 `固定到屏幕`：把当前合成图放进一个无边框浮动窗口（`level = .floating`，所有桌面空间可见），初始位置跟选区一致，然后结束截图会话。
- 拖拽可以移动；双击或 Esc 关闭；右键菜单有 复制 / 保存 / 关闭；窗口带阴影。可以同时钉多张。

### 4.5 提取文字与翻译（M3）

入口有两个：

1. 顶部模式栏选 `提取文字`，然后框选含文字的区域；
2. 已经有选区时点主工具栏的 `提取文字`。

流程：

- 对选区图像跑 `VNRecognizeTextRequest`（`.accurate`，语言：简体中文、繁体中文、英文、日文、韩文，自动纠错）。
- 在选区旁弹出**提取文字面板**：
  - 识别出的文字按阅读顺序排好，放进可编辑的文本框。
  - 选中部分文字后右键 → 复制（系统原生行为）。
  - 面板底部有 `复制` 按钮，复制全文。
  - 用 `NSDataDetector` 识别文字里的链接，显示为可以点击的链接，点击用默认浏览器打开。
  - 右上角 `关闭`：关掉面板，回到框选状态，可以重新框选。
  - 没识别到文字时显示"未识别到文字"。
- **翻译**：
  - 面板里有 `翻译` 按钮，**只在 macOS 15 及以上显示**（`if #available(macOS 15, *)`）。
  - 目标语言：原文以中文为主时翻译成英文，否则翻译成简体中文；面板里可以改。
  - 用 SwiftUI 的 `.translationTask` 拿到 `TranslationSession` 做翻译；需要的语言包没下载时，系统会自己弹下载提示。
  - 面板在原文和译文之间切换显示，`复制` 复制当前显示的内容。

### 4.6 滚动截图（M4）

入口：顶部模式栏的 `滚动截图`，或者主工具栏的 `滚动截图`。

1. 框选要滚动截取的区域。选区旁边提示："只框选会滚动的内容，避开滚动条、固定不动的元素和视频动画。"
2. 点 `开始滚动截图`：
   - 遮罩变成**鼠标可以穿透**（`ignoresMouseEvents = true`），只保留选区边框和控制条可以点，让滚轮事件传到下面的 App。
   - 用 `SCStream` 以 15 fps 抓取选区（`sourceRect`，排除 Reticle 自己的窗口）。
   - 控制条上有：`自动滚动` / `停止滚动`、`完成`、`取消`，旁边显示实时拼接的长图缩略预览。
3. **手动滚动**：用户用滚轮上下滚，两个方向都支持。
4. **自动滚动**：第一次用时检查辅助功能权限（`AXIsProcessTrustedWithOptions`，没有就弹引导）。有权限后，每 50 ms 在选区中心发一次 `CGEvent` 滚轮事件（向下），拼接检测到内容不再变化（连续 1 秒位移为 0）时自动停下；用户也可以点 `停止滚动`。
5. **拼接算法**（ReticleCore/Stitch，纯函数，可以单测）：
   - 每一帧转成灰度，缩到宽 256 像素，算每一行的哈希或特征。
   - 跟上一帧做纵向位移搜索（只在 ±80% 帧高的范围内搜），用逐行差异最小的位移作为 Δy；匹配质量低于阈值就丢弃这一帧，并提示"滚动太快，请慢一点"。
   - Δy > 0 往下追加新的行，Δy < 0 往上追加（支持向上滚），保存画布当前覆盖的纵向范围。
   - 长图高度上限 30000 像素，到达上限自动结束并提示。
6. **完成后**有四个操作：`编辑`（在可滚动的窗口里打开标注画布，编辑完再保存或复制）、`保存`、`取消`、`保存到剪切板`。

### 4.7 录屏（M5）

1. 按 ⌥⇧R（或在菜单栏菜单选"录屏"）→ 进入和截图一样的框选界面（包括窗口识别）。
2. 选好区域后，控制条上显示格式选择 **MP4 / GIF**（默认 MP4）和 `开始录制`。
3. 录制中：
   - 选区边框变成红色虚线，遮罩消失，不影响操作下面的内容。
   - 小控制条上显示已录时长和 `结束录屏`。
   - `SCStream`（`sourceRect` = 选区，显示鼠标指针，30 fps）→ `AVAssetWriter`，H.264 编码写到临时目录的 MP4。
   - 录满 **1 小时**自动结束。
   - 不录音频。
4. 结束后弹出预览窗口：
   - 用 `AVPlayerView`，调用系统自带的**剪辑界面**（`beginTrimming`）调整时长。
   - `下载`：弹保存面板选择存储路径。MP4 直接导出剪辑后的片段；GIF 按 10 fps、最长边不超过 960 像素转码。
   - `复制到剪贴板`：先导出到临时文件，再把文件 URL 写进剪贴板，可以直接粘贴到聊天软件或 Finder。原始录制文件在 App 退出时清理；复制到剪贴板用的导出文件保留 24 小时（避免退出后粘贴失效），下次启动时清理过期文件。

### 4.8 截图历史（M6）

- **记录**：截图的“保存到剪切板 / 下载 / 固定到屏幕”，以及长图窗口的“保存到剪切板 / 保存”。录屏和提取文字不记录。
- **存储**：`~/Library/Application Support/<bundle id>/History/`，每条一张 PNG + 160 px 缩略图，`index.json` 为索引，最多 20 张，超出删除最旧的。写入在后台队列。索引缺失或损坏时从空开始并清理孤儿文件，图片被删的条目自动剔除。
- **菜单**：菜单栏 › 最近截图，打开时才加载缩略图、关闭即释放。每行显示时间和像素尺寸：点击重新复制，按住 ⌥ 点击用预览打开；底部“在访达中显示”“清空历史…”（需确认）。
- **设置**：“保存截图历史”开关，默认开启；关闭后不再记录，已有历史保留到清空。

## 5. 错误处理

| 场景 | 处理 |
|---|---|
| 没有屏幕录制权限 | 不进入截图会话，弹引导窗口 |
| 截图时某块屏幕取图失败 | 该屏幕的遮罩显示错误提示，其他屏幕正常 |
| 快捷键被占用 | 菜单项显示警告，设置页提示改键 |
| OCR 没结果 | 面板显示"未识别到文字" |
| 翻译语言包没下载或下载失败 | 使用系统下载提示；失败时面板显示错误，原文不受影响 |
| 拼接匹配失败 | 丢弃这一帧，提示"滚动太快" |
| 没有辅助功能权限 | 自动滚动按钮点了之后弹引导；手动滚动照常可用 |
| 录屏写入失败（磁盘满等） | 停止录制，弹窗说明原因，保留已写入的部分 |
| 保存文件失败 | 弹窗说明原因，截图会话不关，可以重试 |

## 6. 测试策略

- **单元测试（`swift test`，ReticleCore）**：
  - Geometry：坐标系换算、手柄命中、选区缩放和边界约束、窗口吸附选择。
  - Annotation：各类标注的命中测试、平移、标签翻转。
  - History：撤销和重做的边界（空栈、超过上限）。
  - Render：对小尺寸合成图做像素断言，比如矩形边框像素颜色、马赛克区域是块状、选区外的内容被裁掉。
  - Stitch：用程序生成的长图切出重叠帧，验证拼接结果和原图逐像素一致，覆盖向下、向上和含噪声的情况。
  - Export：PNG 和 GIF 能编码并解码回来，帧数和尺寸正确。
- **App 层**：每个里程碑结束时按验收清单手测（多显示器、Retina 和非 Retina 混合、深色和浅色模式、全屏 App 所在的空间）。
- **性能验收**：每个里程碑结束时用 `footprint`/Activity Monitor 记录空闲内存和截图峰值内存，结果写进提交说明。
- **CI（GitHub Actions，macos-15 runner）**：`xcodegen generate` → `xcodebuild build` → `swift test`；打 tag 时额外 `hdiutil` 打包 DMG 并上传到 Release。

## 7. 开发注意事项

- **TCC 权限和签名**：ad-hoc 签名的 App 每次重新构建，签名都会变，屏幕录制权限会失效。本地开发用钥匙串里自建的"Reticle Dev"自签证书固定签名身份。
- **遮罩层级**：遮罩要盖住全屏 App 所在的空间，设置 `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]`。
- 截图会话期间 App 要临时 `activate` 才能收到键盘事件，结束后把焦点还给原来的 App。
