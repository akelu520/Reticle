**Goal:** 在没有人工操作的情况下验证 M1–M5 的全部功能，并尽量覆盖真实屏幕路径。

**Architecture:** DEBUG 构建内置 `EndToEndTests`：用 `NSWindow.sendEvent` 投递合成鼠标/键盘事件驱动真实视图，按钮用 `performClick`；静态演示图替代截屏；真实屏幕段用独立辅助程序（`scripts/e2e-scroll-target.swift`，必须是另一个 App，因为截图会按 App 排除 Reticle 自己的窗口）显示并自动滚动长页面。`scripts/e2e.sh` 一键编译与运行，`scripts/e2e-verify-scroll.swift` 逐行校验真实滚动拼接。

### 测试发现并修复的问题 ✅
1. 单击选窗口依赖“最后一次悬停”——未移动鼠标就单击会选中整屏 → 改为按按下位置识别窗口
2. 选区换算像素时浮点误差多出 1 px（756×2=1512.0000000001）→ 取整加容差，补单元测试
3. 贴图窗口被取整后图像被轻微缩放 → 窗口尺寸 = 图像像素 / 缩放倍数，内容 1:1 居中
4. 长图窗口未激活时第一次点击不绘制（底图视图挡住点击）→ 底图不参与命中测试、文档视图 acceptsFirstMouse
5. 置顶/浮动窗口（画中画等）无法被窗口识别 → 纳入 Dock 以下所有层级
6. 翻译在未下载语言包时卡在“翻译中…”（系统下载弹窗可能被遮罩挡住）→ 先查 LanguageAvailability，未下载时提示并提供“去下载”（先关闭截图再打开系统设置）
7. 短文本语言识别错误（“Reticle demo”判成其他语种 → “暂不支持”）→ 限定在 5 种支持语言内识别，补单元测试
8. Debug 构建下拼接每帧约 1 s，真实滚动会跟不上 → ReticleCore 在 Debug 也用 -O
9. 马赛克改为纯 CoreGraphics 实现，不再拉起 CoreImage/Metal
10. 录屏预览窗口关闭时释放 AVPlayer
